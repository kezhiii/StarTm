# 显示阶段目前只按三星共同几何可见排，地影和夜间背景不参与判定

晨昏轨道报告第 442 到 445 行的任务排程里，显示阶段的起止就是三星共同几何可见区间的起止（仰角门限 10°），前后各加 300 秒作转向与恢复。经确认，当前显示区域仅由合肥可见性决定，**不叠加地影条件，也不叠加目标区是否处于黑夜**。

这与总体方案不一致，是有意保留的差距而不是笔误：4.3.1 写"对地显示功率最高，且安排在地影区"，4.3.3 写"载荷只在地影区择机工作，单次任务持续时间不超过当次连续地影时长的一半"。按报告实跑结果，该轨道 24 小时日照 86400 秒、半影 0、本影 0，连续地影时长为零，地影条件一叠加可用时长就归零。

## Consequences

- 报告统计的 1295 秒显示时长里，896 秒目标区太阳高度为正（窗口 1 为 +17.05°→+15.66°，窗口 3 为 +4.29°→+6.06°），余下 399 秒太阳在 −3.19° 到 −4.60°，仍在民用昏影内，没有一段是黑暗夜空。这些时刻的显示效果不具备肉眼可辨识度。
- 方案 2.2.3 定义的有效显示要同时满足任务时段、目标可见、目标入锥、姿态稳定、能源与温度五项；当前数据只支撑"目标可见"这一条。
- 晨昏轨道下"卫星不受地影"和"目标区是黑夜"两件事难以同时成立，要真黑夜就得把降交点地方时从 18:00 往后挪，随之 β 角下降、卫星开始进影，能源账重算。这条留给轨道与显示载荷两方定，不在本系统内解决。
- 飞行模拟仿真系统必须把目标区太阳高度作为可见的量呈现，不能因为判定不用就藏掉。具体做法定为可配置门限：太阳高度作为一列数值和一条曲线始终显示，同时预留一个默认关闭的阈值项参与"有效显示"着色，轨道与显示载荷两方定了口径之后填数启用，不改代码。
